# 씨클로 × 238LAB 이식 플랜

**전제**: 씨클로 디자인 시스템(크림 `#F4F1EA` · 네이비 `#111E6C` · 옐로 `#FAE100` · Archivo)은 유지.
238LAB에서 가져오는 것은 **콘텐츠 구성 · 문체 · 모션 · 타이포 메트릭** 네 가지.

측정: 2026-09-13, 1440x900 헤드리스 크롬, `getComputedStyle` 실측.
대상: `ciclo.kr/` · `238lab.kr/` · `238lab.kr/seo-consulting` · `238lab.kr/medical-seo-success-case`

## 0. 먼저 정할 것 — 히어로 (내가 못 정하는 결정)

238LAB h1은 **한글 문장 60px/700**이고, 씨클로 h1은 **영문 디스플레이 168px/900 Archivo**다.
"80% 벤치마킹"을 글자 그대로 하면 `CREATIVE CLICKS.`를 버리고 한글 문장형 히어로로 가야 한다.

그런데 그건 씨클로가 238LAB보다 확실히 나은 유일한 지점이다. 238LAB 히어로는
SEO와 아무 상관 없는 유리빌딩 스톡 사진 + 60px 한글 문장이고, 기억에 남지 않는다.

**권고: 히어로만 예외로 두고 유지한다.** 대신 히어로 아래 모든 섹션 제목을 한글 문장형으로 바꾼다.
설득의 일은 h1이 아니라 섹션 h2가 하게 만드는 것 — 이게 238LAB 구성의 실제 엔진이다.

→ 이 결정에 따라 아래 D(타이포)의 h1 행이 갈린다. 나머지는 동일.

## A. 콘텐츠 구성 — 핵심

### A-1. 238LAB 섹션 원자 구조 (전 섹션 반복 확인)

```
① 눈썹      영문 대문자 · 14px/600 · ls 0.24em        예) WHY SEO
② h2        한글 문장형 2줄 · 36px/700/1.25 · ~합니다
③ 리드      1문장 · 18px/400/1.556 · 숫자와 기준연도 포함
④ 인라인 링크 텍스트+화살표 (버튼 아님)                  예) 업종별 성공사례 확인하기 →
⑤ 증거      이미지 / 차트 / 카드 그리드
⑥ 출처 캡션  12~14px 회색                              예) 25년 9월 statcounter, South Korea 기준
```

씨클로 현재 섹션은 `①눈썹 → 영문 h2 → ⑤아이템`. **③④⑥이 통째로 없다.**
이 세 슬롯이 "광고"와 "리포트"를 가르는 지점이다.

- ③ 없음 → 섹션이 무슨 주장을 하는지 문장으로 안 나옴
- ④ 없음 → 섹션마다 막다른 길, 다음 행동이 없음
- ⑥ 없음 → 숫자를 써도 검증 불가로 읽힘

### B-1. 씨클로 칼럼 문체가 238LAB보다 낫다

이건 그대로 벤치마킹하면 손해다. 비교:

> **238LAB**: AI 검색은 구조화된 SEO 데이터를 우선 평가하며, 이삼팔랩은 GEO·AEO까지 연결되는 SEO 구조를 설계합니다.

**결론**: 238LAB에서 가져올 건 문장의 *톤*이 아니라 *구조 규칙*이다. 톤은 씨클로 칼럼 것을 홈으로 끌어올린다.

### C-2. 가장 중요한 발견 — weight 500 문제

씨클로는 본문을 전부 **500**으로 깐다. 부제도 500, 카드 본문도 500.
그래서 본문 안에 위계가 없다. 238LAB은 **400을 기본**으로 두고 600/700을 위계에만 쓴다.

→ `body { font-weight: 400 }`로 내리고, 강조에만 500/600을 쓰는 것만으로 밀도가 살아난다.
이건 한 줄 수정으로 체감이 가장 큰 항목이다.

### C-3. 목표 토큰

```css
:root{
  /* 폰트 */
  --f-display: Archivo, sans-serif;                    /* 눈썹·숫자·영문 전용 */
  --f-text: "Pretendard Variable", Pretendard, sans-serif;

  /* 크기 / 굵기 / 행간 / 자간 */
  --t-h1:      168px; --w-h1: 900; --lh-h1: 0.92;  --ls-h1: -.03em;  /* 히어로 유지 */
  --t-h2:      40px;  --w-h2: 700; --lh-h2: 1.25;  --ls-h2: -.025em; /* 한글 문장형 */
  --t-h3:      24px;  --w-h3: 700; --lh-h3: 1.5;   --ls-h3: -.025em;
  --t-lead:    18px;  --w-lead: 400; --lh-lead: 1.55;
  --t-sub:     20px;  --w-sub: 400;  --lh-sub: 1.4;   /* 히어로 부제 */
  --t-card-h:  16px;  --w-card-h: 600; --lh-card-h: 1.5;
  --t-card-b:  14px;  --w-card-b: 400; --lh-card-b: 1.62;
  --t-eyebrow: 14px;  --w-eyebrow: 600; --ls-eyebrow: .24em;
  --t-caption: 13px;  --w-caption: 400; --lh-caption: 1.6;

  --body-weight: 400;      /* 500에서 내림 — C-2 */
  --body-lh: 1.7;          /* 1.5에서 올림 */
  --sect-pad: 160px;       /* 140에서 올림 */
  --shell: 1200px;         /* 1140에서 올림 */
  --radius: 4px;           /* 알약 20px 폐기 */
}
```

모바일: h2 40 → 28px, 섹션 패딩 160 → 80px, 눈썹 14 → 12px.

### D-2. 결론

238LAB은 **의도적으로 거의 움직이지 않는다.** 리포트처럼 보이려는 선택이다.
"모션 80% 벤치마킹"의 실제 내용은 **모션을 지우는 것**이다.

| 조치 | 대상 |
|---|---|
| 제거 | 스크롤 리빌 22개 전부 |
| 제거 | 무한 회전 배지 2개 (`spin` 40s / 16s) |
| 유지·감속 | 마퀴 26s → 40s linear |
| 통일 | 호버 트랜지션 전부 `0.15s cubic-bezier(.4,0,.2,1)` |
| 신규 | 헤더 `backdrop-filter: blur(8px)` + 반투명 배경 + 0.2s |
| 신규 | 이미지 `opacity .7s` 페이드인 |
| 유지 | 사이드바 0.38s (열고 닫는 건 리빌이 아니라 상태 전환) |

### D-3. ★ 발견한 버그

씨클로 홈을 **끝까지 스크롤해도 `opacity < 0.9`로 남아 있는 노드가 5개** 있다.
리빌 IntersectionObserver가 일부 요소에서 발화하지 않고, 그 콘텐츠는 영구히 반투명하게 남는다.

리빌을 전부 걷어내면 이 버그도 같이 사라진다. D-2의 1번 조치가 버그 수정을 겸한다.
