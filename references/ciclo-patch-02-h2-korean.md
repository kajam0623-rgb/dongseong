# 씨클로 홈 패치 02 — 섹션 h2 한글 문장형 전환

238LAB 이식 플랜 실행 4번. `references/238lab-adoption-plan.md` A-2 기준.

**핵심**: 영문 대문자 h2(`WHAT WE DO`)를 눈썹으로 강등하고, h2 자리에 한글 문장을 넣는다.
Archivo 정체성은 눈썹에 남기고, 설득의 일은 한글 문장이 하게 만든다.

패치 01(`ciclo-patch-01-typography-motion-radius.css`)이 먼저 적용돼 있어야 한다.

---

## 1. 왜 이걸 하나

238LAB 섹션 제목은 예외 없이 한글 문장이고 `~합니다`로 끝난다.
공식은 **`[수식·방법구] + , + [핵심 동사구 ~합니다]`** 2줄이다.

| 238LAB 실제 h2 | 앞 | 뒤 |
|---|---|---|
| 축적된 실험 데이터와 전략으로, / 재현 가능한 SEO·GEO 성과를 제공합니다 | 방법 | 결과 |
| 지속 가능한 SEO·GEO 체계를 구축해 / 장기 유입 자산으로 내재화 합니다 | 행위 | 결과 |

씨클로 h2는 `WHAT WE DO` / `SELECTED WORK` — **라벨이지 주장이 아니다.**
섹션이 무슨 말을 하려는지 문장으로 나오지 않으니, 스크롤하는 사람이 읽을 게 없다.

문체는 238LAB이 아니라 **씨클로 칼럼 문체**를 쓴다(플랜 B-1). 원장님 2인칭, 짧은 단정문.

---

## 2. 카피 — 6개 섹션 전체

`<br>` 위치가 곧 쉼표 위치다. 두 줄로 떨어지게 짰다.

### ① 서비스

```
현재   눈썹  /SERVICES
      h2   What we do        (화면에는 WHAT WE DO)

변경   눈썹  /SERVICES · WHAT WE DO
      h2   예쁘게 만드는 일과 검색되게 만드는 일을,
           따로 맡기지 않으셔도 됩니다
```

대안(더 담백): `검색으로 찾아오는 구조를,<br>제작 단계에서 함께 설계합니다`

### ② 사례

```
현재   눈썹  /WORK
      h2   Selected work

변경   눈썹  /WORK · SELECTED WORK
      h2   치과 여덟 곳을 직접 채점하고,
           고칠 자리를 숫자로 짚었습니다
```

플랜 A-3의 진단 카드로 교체할 섹션이라 카피를 먼저 맞춰 둔다.
지금은 목업 1장이지만, 이 제목이 들어가면 목업을 오래 두기 어려워진다 — 그게 의도다.

### ③ 프로세스 (네이비 섹션)

```
현재   눈썹  /PROCESS
      h2   How we work

변경   눈썹  /PROCESS · HOW WE WORK
      h2   진단부터 성장까지,
           한 팀이 네 단계로 책임집니다
```

`한 팀이 ~ 책임집니다`는 현재 About 본문에 이미 있는 표현이다. 위로 끌어올린 것.

### ④ 소개

```
현재   눈썹  /ABOUT
      h2   Ciclo

변경   눈썹  /ABOUT · CICLO
      h2   예쁘기만 한 사이트가 아니라,
           문의로 이어지는 사이트를 만듭니다
```

이것도 현재 About 본문 마지막 문장이다. 씨클로에서 제일 좋은 문장인데 본문에 묻혀 있었다.

> **★ About은 레이아웃도 함께 바뀐다.**
> `.about-grid` 가 `241.6px / 362.4px` 2단이고 제목 컬럼이 **242px** 다.
> "Ciclo" 한 단어용으로 짠 폭이라 40px 한글 문장을 넣으면 **7줄(350px)로 터진다** — 실측 확인.
> 패치 02 CSS 5번이 이 그리드를 1단으로 바꿔 제목을 전폭(676px)으로 올린다.
> 238LAB 섹션 문법도 세로 적층이라 방향이 맞다.
>
> **본문에서 마지막 문장을 지울 것.** h2로 올라갔으므로 그대로 두면 같은 문장이 두 번 나온다.
> 남길 본문: `씨클로는 병원·법률·전문직처럼 ~ 한 팀이 처음부터 끝까지 책임집니다.` 까지.

### ⑤ FAQ

```
현재   눈썹  /FAQ
      h2   Questions

변경   눈썹  /FAQ · QUESTIONS
      h2   견적서를 받으셨을 때,
           항목을 짚으실 수 있게 적었습니다
```

238LAB FAQ 철학("다른 업체 견적서를 받으셨을 때 이 표를 꺼내 항목을 짚으실 수 있으면
그게 이 글의 쓸모입니다")을 씨클로 어조로 옮긴 것. 플랜 A-5의 FAQ 확장과 짝이다.

### ⑥ 문의 (푸터)

```
현재   눈썹  /CONTACT
      h2   Let's talk.        (96px, .sec-h2 클래스 없음)

변경   눈썹  /CONTACT · LET'S TALK
      h2   무엇부터 손봐야 할지,
           하루 안에 답을 드립니다
```

`하루 안에`는 현재 부제("하루 안에 답변드립니다")에 있던 약속. 제목으로 올렸다.
이 섹션은 마무리 장식이라 영문 유지도 선택지다 — 다만 전환에 기여하는 건 한글 쪽이다.

### 히어로는 그대로

`/DIGITAL AGENCY — SEOUL` + `Creative Clicks.` 158.4px Archivo 900 — **손대지 않는다.**
238LAB 대비 씨클로가 확실히 나은 지점이고, 이번 전환의 전제(플랜 §0)다.

## 3. HTML 수정

`.ciclo-page` 커스텀 HTML 안에서 **텍스트만** 바꾼다. class 속성은 그대로 둔다.

수정 전:
```html
<div class="overline reveal">/SERVICES</div>
<h2 class="sec-h2 reveal">What we do</h2>
```

수정 후:
```html
<div class="overline reveal">/SERVICES · WHAT WE DO</div>
<h2 class="sec-h2 reveal">예쁘게 만드는 일과 검색되게 만드는 일을,<br>따로 맡기지 않으셔도 됩니다</h2>
```

나머지 5개도 같은 방식. 네이비 섹션(`/PROCESS`)은 `overline light` 클래스가 붙어 있으니 유지.

`reveal` 클래스는 패치 01이 무력화해 둬서 남겨도 무해하다. 정리하고 싶으면 지워도 된다.

### 찾을 위치

`.ciclo-page` 래퍼의 부모가 `.page-content`이고 Gutenberg 블록이 0개다.
→ 페이지(page-id-263)의 **커스텀 HTML 블록** 또는 자식 테마의 페이지 템플릿.
Elementor 위젯이 아니므로 위젯 편집기에서 찾지 말 것.

## 4. CSS

`ciclo-patch-02-h2-korean.css` 를 패치 01 **뒤에** 붙인다.

바뀌는 값:

| | 현재 | 변경 |
|---|---|---|
| `.overline` | 13px / 700 / ls .22em | **14px / 600 / ls .24em** |
| `.sec-h2` 폰트 | Archivo 900 | **Pretendard 700** |
| `.sec-h2` 크기 | clamp(40px, 5.5vw, 80px) | **clamp(28px, 3.2vw, 40px)** |
| `.sec-h2` 행간 | 1.0 | **1.25** |
| `.sec-h2` 자간 | −.02em | **−.025em** |
| `.sec-h2` 변형 | `uppercase` | **none** ★ |
| 푸터 h2 | 96px Archivo 900 | **clamp(28px, 3.2vw, 40px) Pretendard 700** |

★ `text-transform: uppercase` 해제가 필수다. 한글에는 영향이 없지만
문장 안에 섞인 라틴 문자(GEO, AI 등)가 원치 않게 대문자로 바뀐다.

## 5-1. 검증 결과 (실사이트 주입, CSS + 텍스트 치환)

| 뷰포트 | h2 크기 | 줄 수 | 가로 오버플로 | About 제목 폭 |

수정 과정에서 잡은 것 두 가지:

   `@media` 안의 `.sec-h2` (0,1,0)는 `!important` 끼리도 밀렸다.
   미디어쿼리 셀렉터에도 `#ciclo-home` 을 붙여 해결.

## 6. 이후 영향

- h2에 한글 키워드가 들어가면서 **홈 페이지의 검색·AI 인용 표면이 늘어난다.**
  지금 홈 h2 6개는 전부 영문 일반명사라 검색어와 겹치는 게 없었다.

  플랜 A-3(진단 카드 6장)을 이어서 하는 게 맞다.
