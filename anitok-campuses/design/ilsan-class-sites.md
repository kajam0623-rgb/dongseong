# 일산 반 사이트(주니어 · 성인취미) 디자인 프롬프트

## 지금 별로인 이유
- 캠퍼스 템플릿을 색만 바꿔 쓴 것처럼 보인다. 모든 섹션이 '가운데 제목 → 카드 격자'의 같은 리듬이다.
- 첫 화면이 어두운 막을 씌운 사진 위 흰 글자라, 흰 바탕 사이트인데 첫인상은 어둡고 사진도 흐리다.
- 카드 테두리 · 배지 · 둥근 버튼이 많아 '템플릿 느낌'이 난다.

## 방향: 미술관 도록 같은 에디토리얼
학원 사이트가 아니라 **작품을 소개하는 도록**처럼. 여백이 내용이고, 사진은 크고 선명하게, 글자는 크고 정돈되게.

1. **첫 화면 좌우 분할** — 왼쪽 흰 면에 큰 제목, 오른쪽 절반은 사진이 꽉 찬다. 사진 위에 막을 씌우지 않는다.
   세로 사진(취미반 영상 장면)은 오른쪽 세로 칸에 원래 해상도로 들어가 선명하다.
2. **섹션 머리는 왼쪽 정렬 2단** — 왼쪽: 번호(01, 02…) + 소제목 + 큰 제목 / 오른쪽 아래: 설명 한 단락.
   가운데 정렬 제목을 모두 없앤다.
3. **카드 상자를 없앤다** — 반 소개는 큰 사진 + 그 아래 글. 테두리 · 그림자 없음. 사진 모서리는 4px.
4. **리듬** — 흰 섹션 사이에 딱 한 번 검은 띠(단계 섹션)를 둔다. 주황 숫자가 검정 위에서 산다.
5. **FAQ 는 2단** — 왼쪽에 제목, 오른쪽에 질문 목록. 1px 선으로만 구분.
6. **색** — 흰 #FFFFFF, 먹색 #111214, 회색 글자 #5B5B63, 선 #E7E2DC.
   빨강 #BD0D16 은 누르는 것(전화 · 예약 · 상단 버튼)에만. 주황 #F26B1D 는 섹션 번호 · 단계 번호 · 가는 선에만.
7. **글자** — Pretendard 하나. 큰 제목 clamp(34px, 4.4vw, 62px) / 700 / 자간 -0.045em / 행간 1.15.
   설명 17~18px / 행간 1.85. 레이블 12px / 600 / 자간 0.2em.
8. **버튼 · 배지** — 알약 모양 대신 모서리 2px 의 반듯한 사각형. 배지는 1px 선 텍스트.
9. **움직임** — 사진은 마우스를 올리면 1.03배로 천천히(0.9s). 튀는 움직임 없음.

## 지키는 것
- 문구 · 사진 구성 · 링크는 그대로. 학생 실명 없음, 학원비는 네이버 지도 안내.
- 모바일(≤760px)은 1단으로 접고, 첫 화면은 사진이 위 · 글이 아래.
- 다른 캠퍼스의 CSS 는 바꾸지 않는다(junior · hobby 스킨에만 적용).
