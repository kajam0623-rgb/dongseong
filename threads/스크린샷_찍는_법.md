# 스크린샷 네 장 찍는 법

30분이면 끝난다. 넷 다 크롬에서 찍는다.

**전체 규칙 하나.** 남의 병원 화면을 찍을 때는 병원 이름과 주소창의 도메인을 가린다.
리포트를 A부터 H까지 익명으로 냈는데 스크린샷에 실명이 나오면 앞뒤가 안 맞는다.
캡처한 뒤 그림판이나 미리보기로 그 부분만 검은 사각형을 덮으면 된다.

---

## 1장 — 챗지피티가 점수 매긴 화면 (1번 글용, 제일 중요)

원장님이 만든 사이트로 찍는다. 점수가 잘 나오는 쪽이라 결과가 깔끔하다.

1. 크롬에서 그 사이트를 연다
2. 빈 곳에 마우스 오른쪽, 페이지 소스 보기
3. 새 탭에 소스가 뜨면 Ctrl+F 누르고 `</head>` 검색
4. 맨 위부터 그 줄까지 드래그해서 Ctrl+C
5. 챗지피티에 붙여넣고 이렇게 친다

```
병원 홈페이지 소스의 head 부분이야. SEO랑 GEO 점수 매기고 장점 단점 알려줘.
```

6. 답변에서 점수가 보이는 부분을 캡처한다

윈도우는 Win+Shift+S, 맥은 Cmd+Shift+4로 원하는 영역만 자른다.
프롬프트 친 부분까지 같이 나오게 찍는다. 원장님들이 그대로 따라 할 수 있어야 한다.

---

## 2장 — 주소창 비교 (2번 글용)

위아래로 붙인 한 장을 만든다.

1. 진료과목이 나뉜 치과를 열고 임플란트를 클릭한다. 주소창에 `/implant` 같은 게 붙는다
2. 주소창만 나오게 가로로 길게 캡처한다
3. 원페이지 치과를 열고 똑같이 임플란트를 클릭한다. `#implant`가 붙는다
4. 같은 크기로 캡처한다
5. 두 장을 위아래로 붙인다. 도메인은 가린다

윈도우 그림판에서 캔버스 늘려 붙이면 되고, 폰이면 아무 이미지 합치기 앱이나 쓰면 된다.

---

## 3장 — ld+json 검색 결과 (3번 글용)

1. 점수 낮은 치과 사이트를 열고 페이지 소스 보기
2. Ctrl+F 누르고 `ld+json` 입력
3. 검색창에 결과 개수가 뜬다. 0이거나 안 나오는 상태가 보이게 캡처한다
4. 도메인은 가린다

**한 장 더 찍으면 좋다.** 원장님 사이트로 같은 걸 해서 결과가 나오는 화면을 찍고
두 장을 나란히 붙인다. 안 된 예와 된 예가 같이 보이면 훨씬 세다.

---

## 4장 — 챗지피티한테 병원 추천받은 화면 (6번 글용)

1. 챗지피티를 켠다
2. 병원 이름은 빼고 지역과 진료만 넣어 묻는다

```
○○동 임플란트 잘하는 치과 추천해줘
```

3. 답변에 병원 이름들이 나온 화면을 캡처한다

지역은 실제 동네 이름을 쓴다. 강남처럼 큰 데보다 작은 동네가 낫다.
큰 지역은 유명 병원만 나와서 원장님들이 남 얘기로 본다.

---

## 찍고 나서

파일 이름을 이렇게 붙여두면 헷갈리지 않는다.

```
1_챗지피티_점수.png
2_주소창_비교.png
3_ldjson_없음.png
4_챗지피티_추천.png
```

넷이 다 모이기 전에는 올리지 않는다. 1번 글에 결과 화면이 없으면
해보라고만 하고 뭐가 나오는지 안 보여주는 글이 된다.
